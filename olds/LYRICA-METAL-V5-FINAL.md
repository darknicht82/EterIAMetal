## 📋 PALABRAS CLAVE INDICADORAS POR SUBGÉNERO

### POWER METAL ÉPICO
```
Palabras: gloria, poder, victoria, reino, batalla, conquista, armada, 
legado, eternidad, destino, heroico, coraje, triunfo
Tono: Narrativo heroico, positivo, aspiracional, épico
Métrica: Fluida, rítmica, energética
Recomendación: 150-180 BPM, Weirdness 10%, D/E/A Minor
```

### DOOM METAL
```
Palabras: oscuridad, soledad, muerte, lamento, tristeza, perdición, 
dolor, eterno, luto, desdicha, silencio, vacío
Tono: Melancólico, pesimista, introspectivo, devastador
Métrica: Lenta, pausada, pesada
Recomendación: 60-90 BPM, Weirdness 50%, B/D/E Minor
```

### METAL SINFÓNICO
```
Palabras: castillo, magia, danza, sueño, destino, aventura, belleza, luz, 
cielo, mar, teatro, orquesta
Tono: Épico/fantástico, teatral, grandioso
Métrica: Dramática, fluida, compleja
Recomendación: 130-160 BPM, Weirdness 30%, C#/D/F# Minor
```

### GOTH METAL
```
Palabras: noche, sombra, luto, vacío, nostalgia, pasado, recuerdos, 
frío, tiempo, llorar, duelo, melancolía
Tono: Melancólico, teatral, gótico, nostálgico
Métrica: Dramatizada, pausada, emotiva
Recomendación: 90-120 BPM, Weirdness 35%, F#/B/E Minor
```

### METALCORE MELÓDICO
```
Palabras: ira, odio, lucha, fuego, romper, gritar, caos, agresión, 
rebelión, revolución, coraje, desafío
Tono: Agresivo, energético, visceral, apasionado
Métrica: Rápida, punchy, directa
Recomendación: 160-190 BPM, Weirdness 60%, E/D/F# Minor
```

### FOLK METAL
```
Palabras: pueblo, tierra, naturaleza, montaña, bosque, río, raíces, 
historia, tradición, celebración, ancestros
Tono: Épico/celebratorio, folklórico, terrenal
Métrica: Rítmica, tradicional, grupal
Recomendación: 130-160 BPM, Weirdness 40%, D/A/G
```

### NEOCLASSICAL METAL
```
Palabras: clásico, arte, virtuoso, precisión, maestría, fuego, velocidad, 
técnica, escala, armonía, sinfónico
Tono: Técnico, refinado, virtuoso, elegante
Métrica: Compleja, precisa, arpeggiada
Recomendación: 140-170 BPM, Weirdness 20%, D/E/C# Minor
```
