## 🏗️ PASO 3: METAETIQUETAS DE ESTRUCTURA

### Etiquetas Obligatorias en Lyrics:
- `[Intro]` - Introducción (instrumental/atmosférica)
- `[Verse]` - Verso, desarrollo narrativo
- `[Pre-Chorus]` - Construcción hacia el coro
- `[Chorus]` - Gancho principal, memorable
- `[Bridge]` - Contraste, cambio de perspectiva
- `[Guitar Solo]` - Solo instrumental
- `[Breakdown]` - Sección pesada (metalcore)
- `[Outro]` - Cierre

### Etiquetas Vocales Avanzadas:
- `[Harmonized Chorus]` - Coro armonizado
- `[Layered Vocals]` - Voces en capas
- `[Group Chant]` - Coro grupal
- `[Whispered Vocals]` - Susurros
- `[Screaming Vocals]` - Gritos
- `[Growling Vocals]` - Guturales
- `[Opera Singer]` - Cantante de ópera

### Etiquetas de Dinámica:
- `[Building Intensity]` - Incremento de intensidad
- `[Climactic]` - Clímax
- `[Emotional Build-up]` - Construcción emocional
- `[Anthemic Chorus]` - Coro himno

## ✍️ PASO 4: OPTIMIZACIÓN LÍRICA

### Conteo de Sílabas por Sección:
- **Verso:** 6-10 sílabas/línea
- **Pre-Coro:** 8-12 sílabas/línea
- **Coro:** 6-8 sílabas/línea (pegadizo)
- **Puente:** 8-12 sílabas/línea

### Patrón de Rimas:
- **Verso:** ABAB o AABB
- **Pre-Coro:** ABAB
- **Coro:** AABB (más memorable)
- **Puente:** Flexible

### Optimización:
1. **Métrica consistente:** Mantén sílabas similares por línea en cada sección
2. **Rima multisílaba:** Usa rimas de 2-3 sílabas para mayor impacto
3. **Acentos naturales:** Sílabas fuertes en tiempos fuertes
4. **Repetición estratégica:** Repite frases clave en el coro
5. **Contraste:** Varía energía entre verso (narrativo) y coro (explosivo)

## 🎛️ PASO 5: ADVANCED OPTIONS (Configuración)

```
Weirdness: 50-70%
- 50% = Normal, predecible
- 60% = Variación creativa moderada (RECOMENDADO para metal)
- 70% = Experimental (solo para momentos específicos)
- >70% = Caos (evitar)

Style Influence: 80-100%
- 80% = Adhesión fuerte al género
- 90% = Adhesión muy fuerte (RECOMENDADO)
- 100% = Adhesión máxima

Audio Influence: 70-100% (solo con Persona)
- 70% = Adaptación moderada del timbre original
- 100% = Copia exacta del timbre y arreglo
```
