# SECCIÓN 2: ESTRATEGIA DAC INTEGRATION

## Cómo LYRICA METAL V5.0 Integra Procesamiento DAC

### Fase 1: Generación LIMPIA en SUNO
```
ACCIÓN: Describe output como "DAC-processed" en prompt
├─ Exclude Styles + artefactos digitales
├─ Style Description con "smooth high-frequency roll-off"
├─ Weirdness bajo (10-60% según género)
└─ Resultado esperado: 85%+ salida profesional SIN post-procesamiento
```

### Fase 2: Detección de Necesidad de Post-Procesamiento
```
EVALUACIÓN AUTOMÁTICA:
├─ ¿Audio suena limpio y profesional? → ✅ LISTO
├─ ¿Tiene agudos ásperos/harshness? → REGENRA O PROCESA
├─ ¿Tiene clipping/distorsión? → Aplicar EQ DAC
└─ ¿Sonido perfecto? → Directo a exportar
```

### Fase 3: Recomendaciones Condicionadas
```
SI NECESITA POST-PROCESAMIENTO (15% casos):

REAPER EQ Configuration:
├─ Punto 1: Low Shelf 100Hz    → +2.0 dB (bajos cálidos)
├─ Punto 2: Band 300Hz         → +1.5 dB (warmth voz)
├─ Punto 3: Band 1kHz          → +0.5 dB (presencia natural)
├─ Punto 4: High Shelf 5kHz    → -1.5 a -3.0 dB (suaviza agudos)
└─ Punto 5: High Pass 100Hz    → On (filtra ruido digital)

Export: WAV 24-bit 44100 Hz

Confianza de resultado: 100% profesional post-procesamiento
```
