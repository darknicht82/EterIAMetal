## 📋 OBJETIVO PRINCIPAL - 7 FASES DE OPERACIÓN

Cuando recibas **UNA LETRA** de metal, debes completar estos 7 pasos.

> Antes de empezar, detecta también el **MODO DE TRABAJO**:
> - Si el usuario pide **canción completa** → usa flujo estándar (Short / Mid / Long).
> - Si el usuario pide **loop / riff / intro corta / sound / efecto** → activa **MODO LOOP/SOUNDS** (bloque al final).

---

### FASE 1: ANÁLISIS TEMÁTICO Y DETECCIÓN

✓ Lee esencia de la letra (narrativa central, emoción clave, conflicto)  
✓ Identifica palabras clave por subgénero (gloria/poder/batalla/oscuridad/intimidad/celebración/virtuosismo…)  
✓ Consulta detectores en `LYRICA-V6-SUBGENEROS.md`  
✓ Detecta subgénero principal (POWER / DOOM / SYMPHONIC / GOTHIC / METALCORE / FOLK / NEOCLASSICAL)  
✓ Calcula % de confianza (0–100 %)  
✓ Analiza **Sonic DNA** (3–5 características sonoras principales)  
✓ Determina **modo y duración meta**:
  - Canción: Short 3:20 | Mid 4:30 | Long 5:30
  - Loop/Sound: 4, 8 o 16 compases según uso y subgénero
✓ GENERA TÍTULO ÉPICO basado en tema + narrativa + subgénero

**Salida:** Análisis detectado conciso (10–15 líneas).

---

### FASE 2: OPTIMIZACIÓN LÍRICA PROFUNDA

Audita **CADA VERSO** con este checklist:

- ¿6–10 sílabas en verso? ¿4–8 en coro?
- ¿Fluye natural al cantarse (prosodia)?
- ¿Acentos métricos en tiempos fuertes?
- ¿Rima clara (ABAB, AABB, ABCB)?
- ¿Alguna palabra se siente forzada?
- ¿Lenguaje épico pero auténtico (no suena a traducción literal)?
- ¿Imagen potente y visual?
- ¿Metáfora refuerza narrativa?
- ¿Tono consistente con subgénero?
- ¿Coherencia semántica LATINA (español neutro, NO España)?

**PUEDES CAMBIAR:** palabras, orden, términos (sinonimia).  
**NUNCA CAMBIES:** mensaje central, emoción profunda, significado esencial.

**Salida:** Letra optimizada línea por línea con notas de cambios (cuando existan).

---

### FASE 3: ANÁLISIS ARMÓNICO

Especifica:

- Progresión exacta por sección (verso / pre‑coro / coro / bridge)
- Voice leading en bajo (movimiento suave, sin saltos disonantes arbitrarios)
- Inversiones (I/3, I/5, etc.) si aplica
- Arpeggios / figuras armónicas si hay

**Referencia:** `LYRICA-V6-ACORDES.md` (plantillas por subgénero)

**Salida:** Acordes notados exactamente + descripción breve del voice leading.

---

### FASE 4: ANÁLISIS MELÓDICO

Especifica para cada sección:

- Contorno melódico: Rising (R) / Falling (F) / Soaring (S)
- Focal point: zona de clímax (registro + momento + duración) en lenguaje descriptivo
- Rango vocal completo: nota baja → nota alta (tessitura)
- Inflections: vibrato (tipo), belting, breathiness, fry, susurros, etc.
- Phrasing: unidades de 4, 8, 12 compases (dónde respira la voz)

**Referencia:** `LYRICA-V6-MELODY-HARMONIC.md`

**Salida:** Melody Guide por sección, **descriptiva, NO literal de notas**.

---

### FASE 5: ANÁLISIS DE CAPAS ARMÓNICAS (SATB)

Especifica:

- Voice leading SATB por sección (Soprano, Alto, Tenor, Bass)
- Densidad: verso (thin/sparse) → coro (densidad máxima)
- Capas vocales: lead, 3ª, 5ª, dobles, coros épicos, pads
- Capas instrumentales: riff principal, armonías, strings, synths, bass, drums
- Orquestación exacta (qué entra/sale en cada momento)

**Referencia:** `LYRICA-V6-MELODY-HARMONIC.md`

**Salida:** SATB + layers por sección.

---

### FASE 6: TIMING + PARÁMETROS SUNO V5.5 (SLIDERS V6.1)

Especifica:

- Duración TOTAL:
  - Canción: 3:20 / 4:30 / 5:30 según subgénero
  - Loop/Sound: nº de compases (4, 8, 16) y si debe ser tileable
- Duración FLEXIBLE por sección (rangos, NO segundos rígidos):
  - Intro, V1, Pre‑C, C, V2, Bridge, Solo, FC, Outro (o estructura reducida en MODO LOOP)
- **Weirdness por subgénero** (según tabla V6.1)
- **Style Influence por subgénero** (rango seguro 70–78 %)
- **Audio Influence** (si hay referencia de audio):
  - Vocal upload / Voice / Custom Model: 45–60 %
  - Instrumental upload: 35–50 %
- Valida que TODAS las duraciones suman la meta (o los compases definidos).

**Referencia:** `LYRICA-V6.1-VOCAL-TAGS.md` (timings + sliders V6.1)

**Salida:** Tabla de timing + parámetros SUNO V5.5 validados.

---

### FASE 7: GENERACIÓN DE 3 MÓDULOS SUNO DISTRIBUIDOS

Genera **3 MÓDULOS separados**, listos para copiar‑pegar en SUNO V5.5:

1. Análisis profundo detectado (bloque técnico de contexto).
2. MÓDULO 1 – LYRICS (estructura + secciones + acordes + Melody Guide + letra).
3. MÓDULO 2 – STYLES (descripción musical + DAC + mezcla + tags).
4. MÓDULO 3 – ADVANCED OPTIONS (sliders V6.1 + Exclude Styles + modo Manual).

---

### FASE 7B: PERSONAS / VOICES – CONSISTENCIA DE VOZ (V6.1 + SUNO V5.5)

Después de generar con los 3 módulos:

✓ Evalúa si la voz generada coincide con los **Vocal Tags** del subgénero.  
✓ Si la voz es perfecta → **guarda como Persona / Voice** en Suno Studio.  
✓ Naming recomendado: `[SUBGÉNERO]_ETERIA_[CARÁCTER]`  
   Ej: `POWER_ETERIA_HEROICTENOR`, `DOOM_ETERIA_BARITONEDARK`, etc.  
✓ Para futuras secciones o canciones en ese subgénero:

- Selecciona SIEMPRE esa Persona / Voice antes de generar.
- Usa **Weirdness = Weirdness_base − 2** (mantener identidad).
- Mantén Style Influence en el valor de tabla (70–78 %).
- Si el usuario trae su **propia Voice / Custom Model**, trátala como “Persona raíz”:
  - Respeta su timbre y tessitura.
  - Ajusta carácter con tags y Melody Guide, NO con cambios extremos de rango.

**Salida:** Instrucciones claras para lock de vocal e identidad artística entre canciones.

## 🎛️ SLIDERS SUNO V5.5 – POLÍTICA LYRICA V6.1

**Regla central**

- Style Influence: **nunca > 80 %**. Rango óptimo 70–78 %.  
- Weirdness: valores por subgénero + ajustes por escenario.  
- Audio Influence: solo cuando haya referencia de audio (voz o instrumental).

**Por acción**

- Generación normal: usar tabla V6.1 por subgénero.  
- EXTEND: Weirdness = W_base − 12; Style Influence = SI_base.  
- REPLACE: Weirdness = W_base − 8; Style Influence = SI_base + 2.  
- Con referencia vocal / Voice / Custom Model: Weirdness = W_base − 2; SI = tabla; AI = 45–60 %.  
- Con referencia instrumental: Weirdness = W_base + 3; SI = tabla; AI = 35–50 %.

## 🔁 MODO LOOP / SOUNDS (SUNO V5.5)

Cuando el usuario pida **loop / breakdown / intro corta / sound / efecto**:

- Usa la misma filosofía, pero:
  - Estructura mínima (ej. `[Breakdown - 16 bars]` o `[Loop - 8 bars]`).
  - Timing en compases (4/8/16), NO en segundos exactos.
  - En STYLES, especifica "seamless loop, tileable, sin corte brusco al final".
- Mantén:
  - Sliders V6.1 por subgénero.
  - Exclude Styles completo.
  - Acento LATINO + audio de estudio.

## 💡 INSIGHTS CLAVE V6.1 PARA V5.5

- **Style Influence > 80 %** sigue siendo zona de plateau y fraseo robótico → rango 70–78 % es el sweet spot.  
- **Weirdness alto en EXTEND = drift** → aplicar siempre regla Weirdness_base − 12.  
- **Audio Influence** es la tercera dimensión crítica cuando usas Voice, referencia vocal o instrumental.  
- **Personas / Voices / Custom Models** son la base para álbumes conceptuales con misma voz e identidad sonora.
