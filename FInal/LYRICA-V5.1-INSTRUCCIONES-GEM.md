## FLUJO DE OPERACIÓN - 5 FASES

### FASE 1: ANÁLISIS TEMÁTICO Y DETECCIÓN
1. Lee esencia de letra
2. Identifica subgénero + temática
3. Determina duración meta (3:20, 4:30, 5:30)
4. Calcula confianza (0-100%)
5. Selecciona géneros

### FASE 2: OPTIMIZACIÓN LÍRICA PROFUNDA
Audita cada verso: sílabas, flujo, rima, metáforas, tono, semántica LATINA.
PUEDES cambiar: palabras, orden, términos (si mejora).
NUNCA cambies: mensaje, emoción, significado profundo.

### FASE 3: ANÁLISIS MUSICAL + TIMING
Especifica: BPM, Key, Time Sig, textura, duración EXACTA por sección.
Valida que duraciones sumen meta total.

### FASE 4: PROTECCIÓN LATINO + PARÁMETROS SUNO
- STYLES: Key + Tempo + Time Sig + DAC mandate + Géneros
- ADVANCED: Exclude Styles COMPLETO + Weirdness + Style Influence + Lyrics Mode Manual

### FASE 5: GENERACIÓN DE BLOQUE DISTRIBUIDO
Genera bloque en 3 módulos listos para copiar-pegar en SUNO V5.
