# LYRICA-HARMONIC-LAYERS
## Guía Profesional de Capas Armónicas y Voice Leading para Metal

---

## 🎼 INTRODUCCIÓN

Este documento detalla cómo estructurar capas vocales e instrumentales profesionalmente, aplicando principios de voice leading, orquestación metal y mixing balance para máxima densidad emocional.

**Objetivo:** Instruir a LYRICA sobre cómo mapear capas armónicas complejas en SUNO V5 para conseguir sonido studio-grade profesional.

---

## 1. VOICE LEADING CLÁSICO (SATB)

### Sistema SATB (Soprano, Alto, Tenor, Bass):

**Soprano (S):**
- Rango: Más alto de todas las voces
- Función: Melodía principal, focal point
- Movimiento: Libre, dramático, visible
- En metal: Lead vocals limpio o gritado

**Alto (A):**
- Rango: Segunda voz más alta
- Función: Armonía, soporte emocional
- Movimiento: Complementa soprano
- En metal: Backing vocals (tercera armonía)

**Tenor (T):**
- Rango: Tercera voz más alta
- Función: Puente armonico, groove
- Movimiento: Rítmico, conector
- En metal: Harmonía más baja + lead secundario

**Bass (B):**
- Rango: Más bajo de todas las voces
- Función: Cimiento armónico, root movement
- Movimiento: Lógico, menor saltos
- En metal: Bajo profundo, movimiento de raíz

### Regla Fundamental - Voice Leading Smooth:

**Movimiento de voz:** Cada voz se mueve por grados o reposa en misma nota.

**Exemplo em Dm → G:**
```
ANTES (Dm):          DESPUÉS (G):
Soprano: F ────────→ G (salta tercera, OK épico)
Alto: A ────────→ B (salta tercera, paralelo soprano)
Tenor: D ────────→ G (salta cuarta, movimiento lógico)
Bass: D ────────→ G (salta quinta, root movement)
```

**Resultado:** Sonoridad suave, no "pega" disonante.

## 2. CAPAS VOCALES ESPECÍFICAS POR SECCIÓN

### VERSO - Thin Vocals (Densidad mínima):

**Layer Structure:**
```
Lead Vocal (S): Melody principal (100% presencia)
  └─ Backing Pad (A): Nota única largo (suportea)
  
Efecto: Íntimo, exposición letra clara

Ejemplo Power Metal (Em verso):
Lead: "En el alma oscura" (E-G-B-E)
Backing: "Óhhhhhh" (E sostenido, reverb)
```

**Configuración SUNO:**
```
[Verse 1 - 40s]
[Clean Male Vocals], [Vulnerable Tone]
[Single Backing Note - Long Sustain]
[LETRA]
```

### PRE-CHORUS - Building Layers:

**Layer Structure:**
```
Lead Vocal (S): Melody ascendente (95% presencia)
  └─ Harmony 3ª (A): Tercera abajo (70% presencia)
  └─ Harmony 5ª (T): Quinta arriba (50% presencia)
  
Efecto: Buildup dramático, anticipación

Ejemplo Doom Metal (Bm pre-coro):
Lead: "Donde todo muere" (B-A-G-F#)
Harm 3ª: "Dooonde" (G-F-D-C#)
Harm 5ª: "Moooouere" (F#-E-D-C#)
```

**Configuración SUNO:**
```
[Pre-Chorus - 20s]
[Male Vocals Building], [Harmonized 3-Part]
[Ascending Line with Layer Support]
[LETRA]
```

### CHORUS - Maximum Layers (Densidad máxima):

**Layer Structure:**
```
Lead Vocal (S): Melody heroico/anthemic (100%)
  ├─ Harmony 3ª (A): Tercera abajo (80%)
  ├─ Harmony 5ª (T): Quinta arriba (80%)
  └─ Pad/Drone (B): Nota larga profunda (40%)
  
Efecto: Épico, memorable, pegadizo

Ejemplo Power Metal (Em coro):
Lead: "EN LA GLORIA!!" (E-E-E)
Harm 3ª: "En la glory" (C#-C#-C#)
Harm 5ª: "Eeeeen" (B-B-B)
Pad Bass: "Ehhhhhhhhh" (E2 muy grave)
```

**Configuración SUNO:**
```
[Chorus - 35s]
[Anthemic Male Vocals], [Full 3-Part Harmony]
[Rich Vocal Pad Underneath], [Maximum Emotional Impact]
[LETRA]
```

### BRIDGE - Contrast Vocals:

**Layer Structure - Opción A (Mínima - Gothic/Doom):**
```
Lead Vocal (S): Vulnerable, crudo (100%)
  └─ Ambient Pad: Reverb profundo (30%)
  
Efecto: Intimidad emocional, confrontación interna
```

**Layer Structure - Opción B (Máxima - Power/Symphonic):**
```
Lead Vocal (S): Acelerado, emoción pura (100%)
  ├─ Harmony 3ª (A): Soporte emocional (85%)
  ├─ Harmony 5ª (T): Clímax vocal (85%)
  └─ Group Chant (B): "Ohhhhh" mass (60%)
  
Efecto: Clímax emocional máximo, participativo
```

**Configuración SUNO (Bridge máximo):**
```
[Bridge - 30s]
[Soaring Male Vocals], [3-Part Harmony + Group Chant]
[Emotional Peak], [Maximum Intensity]
[LETRA]
```

## 3. CAPAS INSTRUMENTALES

### Sistema de Capas Instrumental (4 niveles):

**Level 1 - RIFF (Lead instrumental):**
- Melodía principal instrumental
- Nota más visible
- Rango medio a agudo
- Ejemplo: Lead guitar riff, synth melody

**Level 2 - HARMONY (Armonía instrumental):**
- Soporte armónico del riff
- Rango medio
- Complementa riff
- Ejemplo: Segundo guitarra, strings harmony

**Level 3 - PADDING (Textura ambiental):**
- Fondo de sonido
- Crea atmósfera
- Rango bajo a medio
- Ejemplo: Synth pad, strings sustain, keyboard

**Level 4 - BASS/DRUMS (Cimiento):**
- Groove rítmico
- Establece timing
- Rango muy bajo
- Ejemplo: Bajo profundo, double bass drums

### Por Sección:

**VERSO:**
```
Lead Riff: Clean guitar + 1 synth pad (mínima)
Harmony: Ninguna (focus letra)
Padding: Reverb ambient minimal
Bass/Drums: Simple groove (constante)

Efecto: Letra clara, instrumento soporte
```

**PRE-CHORUS:**
```
Lead Riff: Escalada guitarra (building)
Harmony: Strings entrada suave
Padding: Synth swell
Bass/Drums: Aceleración tempo

Efecto: Buildup anticipación
```

**CHORUS:**
```
Lead Riff: Guitar heroico + synth full
Harmony: Strings full orquesta
Padding: Synth pads múltiples + reverb
Bass/Drums: Doble intensidad ritmo

Efecto: Máxima densidad, épico
```

**BRIDGE:**
```
Lead Riff: Solo guitarra/synth (variable)
Harmony: Strings clímax
Padding: Atmospheric pads evolución
Bass/Drums: Doble pedal máximo (si heavy)

Efecto: Clímax emocional
```

## 4. ORQUESTACIÓN METAL (Instrumento por Instrumento)

### GUITARRA ELÉCTRICA:

**Componentes:**
- Clean tone (versos, pre-coros): 8-12 kHz presencia
- Heavy distortion (coros, bridges): 4-6 kHz power
- Lead guitar (solos): 10-15 kHz claridad
- Rhythm power chords: 2-4 kHz grasa

**Estratificación:**
```
Verse: 1 guitarra limpia + 1 pad suave
Chorus: 2 guitarras (riff + harmony) distorsionadas
Bridge: 1 guitarra solo épica
Solo: Lead guitar rápida + pad soporte
```

### BAJO ELÉCTRICO:

**Rango:** 40-250 Hz (fundamental de acordes)

**Técnica:**
- Verso: Root movement suave, octavas ocasionales
- Coro: Root + fifth power, más movimiento
- Bridge: Movimiento complementario a guitarra
- Solo: Groove creativo, syncopation

**Integración:**
```
Em: E (root) o E-B (octava)
Dm: D (root) o D-A (octava)
Bm: B (root) o B-F# (octava)
```

### BATERÍA:

**Groove Base:**
- Verso: Kick simple (kick-kick-kick-kick), snare backbeat
- Coro: Doble kick, snare más agresivo
- Bridge: Doble kick máximo, tom fills
- Solo: Redobles, breaks, cymbal crashes

**Velocidad según BPM/Subgénero:**
```
Power (160 BPM): Doble kick 320 notas/min
Doom (75 BPM): Kick lento, snare largo sustain
Metalcore (175 BPM): Doble kick 350+ notas/min
```

### SINTETIZADOR/TECLADO:

**Funciones:**
- Pad: Sustain emocional (background)
- Swell: Construcción gradual
- Arpeggio: Movimiento rítmico
- Orchestral: Strings, choir, brass simulation

**Rango de frecuencia:**
```
Bass Synth: 60-200 Hz (soporte bajo)
Mid Pad: 200-2000 Hz (cuerpo emocional)
High Synth: 2000-8000 Hz (brillo, presencia)
```

### STRINGS (Violín, Viola, Cello):

**Symphonic Metal principal:**
- Verso: Pizzicato o sustain suave
- Coro: Full sustain emocional
- Bridge: Violín solo + soporte
- Arranjo: 3-parte (violin I, violin II, cello)

**Rango:**
- Violin I: Agudo (melodía)
- Violin II: Medio (armonía)
- Cello: Grave (bass support)

## 5. MIXING BALANCE (Niveles de Volumen Relativos)

### Mix Level Matriz (0 dB = Lead Vocal):

| Elemento | Verso | Pre-Coro | Coro | Bridge | Solo |
|----------|-------|----------|------|--------|------|
| Lead Vocal | 0 dB | 0 dB | 0 dB | 0 dB | -3 dB |
| Backing Vocals | -12 dB | -8 dB | -4 dB | -3 dB | -∞ |
| Lead Guitar | -6 dB | -4 dB | -5 dB | -2 dB | +3 dB |
| Rhythm Guitar | -∞ | -10 dB | -4 dB | -3 dB | -6 dB |
| Bass | -5 dB | -4 dB | -4 dB | -3 dB | -5 dB |
| Drums | -3 dB | -2 dB | -2 dB | -1 dB | -2 dB |
| Synth Pad | -10 dB | -6 dB | -5 dB | -4 dB | -8 dB |
| Strings (Symphonic) | -∞ | -12 dB | -6 dB | -2 dB | -4 dB |

**Interpretación:**
- 0 dB = Referencia lead vocal
- Negativos = Más bajo que referencia
- -∞ = No presente en sección

### Técnica Gain Staging:

```
Paso 1: Setear Lead Vocal a 0 dB (referencia)
Paso 2: Ajustar cada instrumento relativo a vocal
Paso 3: Validar que no hay clipping (> 0 dB peak)
Paso 4: Usar compresión para control dinámico
```

## 6. CONTRAPUNTO Y DIÁLOGO ENTRE SECCIONES

### Concepto: Interacción melódica entre voces:

**Call-Response (Pregunta-Respuesta):**
```
Verso 1 (Call): "En el alma oscura"
Verso 2 (Response): "Donde la noche vive"

Efecto: Narrativa conversacional, engagement emocional
```

**Antiphonal Singing (Dos grupos alternados):**
```
Grupo A: "Gloria!!"
Grupo B: "Poder!!"
Grupo A+B (Unísono): "GLORIA PODER!!"

Efecto: Participatory, épico, tribal
```

**Canon (Mismo riff, desfasado en tiempo):**
```
Guitarra 1: E-G-B-D (empieza)
[2 compases después]
Guitarra 2: E-G-B-D (entra, desfasado)
Resultado: Riqueza armónica, movimiento constante

Uso: Bridges, finales coro
```

## 7. CREACIÓN DE DENSIDAD EMOCIONAL

### Técnica de Capas Progresivas:

**Verso (Mínima densidad):**
```
Compás 1-2: Solo lead vocal
Compás 3-4: Lead + pad suave
Compás 5-8: Lead + pad + bajo suave
→ Construcción gradual, exposición letra
```

**Pre-Coro (Aumento):**
```
Lead + Harmony (3ª) entra
Drums aumentan intensidad
Strings entrada suave
→ Anticipación crecer
```

**Coro (Máxima densidad):**
```
TODAS las capas presentes:
Lead + Harmony (3ª + 5ª) + Pad vocal
Guitarra completa (riff + harmony)
Bass + Drums (máximo)
Strings (if symphonic)
→ Impacto emocional máximo
```

**Bridge (Variable):**
```
Opción A (Emotional drop): Mínimo (solo vocal + pad)
→ Confrontación interna cruda

Opción B (Climactic rise): Máximo + más
→ Soaring épico, clímax absoluto
```

## 8. TÉCNICAS AVANZADAS DE MIXING

### Reverb Estratégico:

**Verse:** Reverb mínimo (0.1-0.3 segundos) = Intimidad

**Coro:** Reverb moderado (0.5-1.5 segundos) = Espacio épico

**Bridge:** Reverb variable:
- Parte 1: Largo reverb (2+ segundos) = Catedral emocional
- Parte 2: Reverb mínimo = Impacto puro

### Delay/Echo:

**Técnica Slapback:**
```
Lead vocal + delay 120 ms (1 beat)
Efecto: Dobling no-latencia, espacialidad

Usado en: Coros anthemic
```

**Técnica Ambient Trails:**
```
Lead vocal + delay largo (500-1000 ms)
Feedback bajo (reverb natural)
Efecto: Atmósfera, misterio

Usado en: Bridges gothicos, doom
```

### Compression (Control dinámico):

**Lead Vocal:**
- Ratio: 4:1
- Threshold: -20 dB
- Efecto: Controlado, no "muddy", claridad

**Bass:**
- Ratio: 6:1
- Threshold: -18 dB
- Efecto: Groove consistente, no "boomy"

**Drums:**
- Ratio: 2:1 suave (glue effect)
- Threshold: -15 dB
- Efecto: Cohesión rítmica, no agresivo

## 9. ARMONIZACIÓN ESPECÍFICA POR SUBGÉNERO

### POWER METAL - Triadas mayores + Épico:

```
Acordes: Em, G, D, A (mayor para brillo)
Voicing Coro:
  Soprano: E (tónica)
  Alto: G (tercera)
  Tenor: B (quinta)
  Bass: E (root)
→ Sonoridad clara, heroica, en unidad

Armonía típica (3-parte):
  Voz 1: "GLORIA!!" (E alto)
  Voz 2: "Gloria..." (G medio)
  Voz 3: "Gloooria..." (B bajo)
```

### DOOM METAL - Triadas menores oscuras:

```
Acordes: Em, Bm, Gm (menor exclusivamente)
Voicing Verso (sostenido lento):
  Soprano: E (tónica baja)
  Alto: G (ninguno - gap intencional)
  Tenor: B (quinta vacía)
  Bass: E (muy grave)
→ Sonoridad hueca, oscura, devastadora

No hay armonía vocal (monofonía pura)
```

### SYMPHONIC METAL - Acordes complejos + Orquestación:

```
Acordes: C#m7, G#sus4, Aadd9 (complejos, lush)
Voicing Coro:
  Soprano: C# (tónica)
  Alto: E (tercera)
  Tenor: G# (quinta)
  Bass: C# (root) + padding A (novena)
→ Sonoridad opulenta, emocional, teatral

Strings soporte: Violín I arriba, Cello abajo
```

### GOTHIC METAL - Acordes menores + Vulnerable:

```
Acordes: F#m, C#m, Bm (menor melancólico)
Voicing Verso (vulnerable, breathy):
  Soprano: F# (pequeño, íntimo)
  Alto: A (soporte emocional)
  Tenor: C# (profundidad)
  Bass: F# (grave lejano)
→ Sonoridad íntima, nostálgica, sombría

Ocasional armonía vocal (2-parte, no dense)
```

### METALCORE - Power Chords + Agresión:

```
Acordes: E5, D5, B5 (quinta exclusively, no tercera)
Voicing Coro:
  Soprano: E (grito puro)
  Alto: G (scream agresivo)
  Tenor: B (grito doble)
  Bass: E (muy grave, distorsionado)
→ Sonoridad neutra aggressive, raw, visceral

Harmonía vocal (2-3 parte): Screams + occasional clean
```

### FOLK METAL - Acordes mayores + Tribu:

```
Acordes: D, A, G (mayor celebratorio)
Voicing Coro (grupo, unísonos frecuentes):
  Soprano: D (melody
  Alto: F# (tercera)
  Tenor: A (quinta)
  Bass: D (root grave)
→ Sonoridad abierta, celebratoria, grupal

Frecuente: Unísono (mismo nota múltiples octavas)
```

### NEOCLASSICAL METAL - Acordes complejos + Técnico:

```
Acordes: Dm, Bbmaj7#5, Gm (Bach-inspired, complejos)
Voicing (Polifónico completo):
  Soprano: D (melodía técnica)
  Alto: F (segunda voz técnica)
  Tenor: A (contrapunto)
  Bass: D (bajo caminante)
→ Sonoridad clásica, precisa, virtuosa

Cada voz tiene movimiento independiente (no bloques)
```

## 10. CHECKLIST FINAL HARMONIC LAYERS

✅ SIEMPRE mapear 4 capas: Soprano, Alto, Tenor, Bass
✅ SIEMPRE validar voice leading smooth (grados conjuntos)
✅ SIEMPRE incluir instrumental layers (riff, harmony, pad, bass/drums)
✅ SIEMPRE especificar mixing levels relativos
✅ SIEMPRE mapear densidad por sección (verso < coro)
✅ SIEMPRE incluir reverb/delay estratégico
✅ SIEMPRE usar compression para cohesión

❌ NUNCA dejar voces "solas" sin contexto armónico
❌ NUNCA saltos extremos entre voces (violate voice leading)
❌ NUNCA saturar verso con múltiples capas
❌ NUNCA olvidar contrapunto y diálogo
❌ NUNCA mezclar densidades (inconsistencia)
