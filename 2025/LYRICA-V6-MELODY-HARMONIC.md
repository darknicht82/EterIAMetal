## MELODY GUIDE FRAMEWORK

### Elementos Fundamentales

**Rising Phrase (R) - "Pregunta"**
- Movimiento ascendente lento
- Crea tensión y búsqueda
- Típico en versos
- Emoción: Investigación, inquietud

**Falling Phrase (F) - "Respuesta"**
- Movimiento descendente controlado
- Resuelve tensión
- Típico en coros
- Emoción: Resolución, conclusión

**Soaring Lift (S) - "Clímax"**
- Salto dramático máximo
- Pico emocional absoluto
- Típico en bridges/final chorus
- Emoción: Épica, triunfo, devastación

### Focal Points por Subgénero

| Subgénero | Nota Focal | Duración | Rango Vocal | Registro |
|-----------|-----------|----------|-------------|----------|
| **Power Metal** | Quinta (G#4) | 2-3 beats | E3→B4 (octava+media) | Tenor heroico |
| **Doom Metal** | Tónica (B3) | 4+ beats | B2→D4 (pequeño) | Barítono profundo |
| **Symphonic** | Octava (C5) | 2 beats | C3→E5 (amplio) | Soprano/Tenor |
| **Gothic** | Tercera (A#3) | 1.5 beats | F#2→F#4 (octava+media) | Barítono vulnerable |
| **Metalcore** | Quinta (A4) | 1 beat | E3→D5 (dos octavas) | Tenor agresivo |
| **Folk Metal** | Segunda (E4) | 2 beats | D3→A4 (octava+media) | Tenor folk |
| **Neoclassical** | Sexta (B4) | 2 beats | D3→E5 (amplio) | Tenor virtuoso |

## PHRASING PATRONES POR SECCIÓN

### Verso (4-8 compases)

**Power Metal Ejemplo (Em):**
```
Compás 1-2: E-F#-G-G (ascenso presentación)
Compás 3-4: A-B-B-B (mantenimiento tensión)
Compás 5-6: B-A-G-F# (descenso parcial)
Compás 7-8: E-E-E (resolución tónica)
Contour: RISING → holding → partial FALLING → RESOLVE
```

**Doom Metal Ejemplo (Em):**
```
Compás 1-8: E-E-E-E-E-E-E-E (nota tónica sostenida)
Contour: STASIS (sin movimiento, melancolía pura)
```

### Pre-Coro (4-6 compases, Building)

**Ascenso Gradual:**
```
Compás 1-2: Intro frase 1 (nota baja)
Compás 3-4: Frase 2 (nota media, sube poco)
Compás 5-6: Frase 3 (nota alta, anticipa coro)
Efecto: Construcción gradual, anticipación
```

### Coro (8-12 compases)

**Power/Symphonic (Máxima Densidad):**
```
Compás 1-4: STATEMENT (idea principal, nota focal sostenida)
Compás 5-8: RESPONSE (reafirmación con variación, sube)
Compás 9-12: CLINAX (pico máximo, resolución épica)
Contour: FALLING con énfasis focal point, memorable
```

### Bridge (8-16 compases, Contraste)

**Opción Emocional Drop (Gothic/Doom):**
```
Compás 1-4: Sola voz vulnerable (intimidad cruda)
Compás 5-8: Entrada suave pad (atmósfera)
Compás 9-16: Lento ascenso (clímax emocional)
Contour: VULNERABLE → BUILD → SOARING
```

**Opción Climactic Rise (Power/Symphonic):**
```
Compás 1-8: Elevación gradual (emoción sube)
Compás 9-16: Clímax máximo (todas capas, nota más alta)
Contour: RISING → SOARING (pico absoluto)
```

## INFLECTION Y TÉCNICAS VOCALES

### Vibrato Estratégico

**Power Metal (2-3 semitones, 5-6 Hz):**
- Ancho, rápido, heroico
- Ejemplo: "GLORIA..." (vibrato épico en "ia")

**Doom Metal (1-2 Hz lento):**
- Ancho pero lento, desvanecimiento
- Ejemplo: "Oscuridaaaaaad..." (vibrato lento, fade)

**Symphonic Metal (1-2 semitones, natural):**
- Moderado, ornamentación operística
- Ejemplo: "Magia..." (ornamentos sutiles)

**Gothic Metal (Subjetil/imperceptible):**
- Casi sin vibrato, vulnerable
- Ejemplo: "Noche..." (crudo, sin vibrato)

**Metalcore (NINGUNO):**
- Limpio cortante, gritado sin vibrato
- Ejemplo: "LUCHA!!" (scream puro)

**Folk Metal (2-3 Hz natural):**
- Potencia grupal, unísono
- Ejemplo: "PUEBLO!!" (sin vibrato, potencia)

**Neoclassical Metal (4-5 Hz controlado):**
- Clásico preciso, Bach-like
- Ejemplo: "Maestría..." (vibrato Bach académico)

## HARMONIC LAYERS - SATB FRAMEWORK

### Estructura de 4 Voces (Soprano, Alto, Tenor, Bass)

**VERSO (Thin Density):**
```
Soprano: Lead vocal (melody, 100% presencia)
Alto: Backing pad nota única larga (30% presencia)
Tenor: (vacío - foco en letra)
Bass: Bajo profundo suave (bajo continuo)
= 2-3 voces mínimas
```

**PRE-CORO (Building):**
```
Soprano: Melody ascendente (95% presencia)
Alto: Harmony 3ª (70% presencia)
Tenor: Harmony 5ª (50% presencia)
Bass: Bajo movimiento constante
= 4 voces construcción gradual
```

**CORO (Maximum Density):**
```
Soprano: Lead vocal heroico/anthemic (100%)
Alto: Harmony 3ª (80%)
Tenor: Harmony 5ª (80%)
Bass: Pad/Drone nota larga profunda (40%)
= 4 voces full density épico
```

**BRIDGE (Variable):**

*Opción A (Drop - Gothic/Doom):*
```
Soprano: Solo vulnerable (100%)
Alto: Ambient pad reverb (30%)
Tenor: (vacío - intimidad)
Bass: Muy grave lejano (20%)
= 2-3 voces intimidad
```

*Opción B (Rise - Power/Symphonic):*
```
Soprano: Lead soaring máximo (100%)
Alto: Harmony 3ª (85%)
Tenor: Harmony 5ª (85%)
Bass: Pad support (40%)
+ Group Chant (adicional, 60%)
= 4+ voces clímax
```

## CAPAS INSTRUMENTALES (4 niveles)

### Level 1 - RIFF (Lead Instrumental)
- Melodía principal instrumental visible
- Rango: Medio-agudo
- Ejemplo: Lead guitar riff, synth melody

### Level 2 - HARMONY (Armonía)
- Soporte armónico del riff
- Rango: Medio
- Ejemplo: Segundo guitarra, strings harmony

### Level 3 - PADDING (Textura Ambiental)
- Fondo de sonido, atmósfera
- Rango: Bajo-medio
- Ejemplo: Synth pad, strings sustain, keyboard

### Level 4 - BASS/DRUMS (Cimiento)
- Groove rítmico, timing
- Rango: Muy bajo
- Ejemplo: Bajo profundo, double bass drums

### Estratificación por Sección

**VERSO:**
```
Lead Riff: Clean guitar + synth pad (mínima)
Harmony: Ninguna (focus letra)
Padding: Reverb ambient minimal
Bass/Drums: Simple groove constante
= Letra clara, instrumento soporte
```

**PRE-CORO:**
```
Lead Riff: Escalada guitarra (building)
Harmony: Strings entrada suave
Padding: Synth swell
Bass/Drums: Aceleración tempo
= Buildup anticipación
```

**CORO:**
```
Lead Riff: Guitar heroico + synth full
Harmony: Strings full orquesta
Padding: Synth pads múltiples + reverb
Bass/Drums: Doble intensidad ritmo
= Máxima densidad épico
```

**BRIDGE:**
```
Lead Riff: Solo guitarra/synth (variable)
Harmony: Strings clímax
Padding: Atmospheric pads evolución
Bass/Drums: Doble pedal máximo
= Clímax emocional
```

## VOICE LEADING SMOOTH - REGLA FUNDAMENTAL

### Principio: Cada voz se mueve por grados o reposa

**Ejemplo Dm → G:**
```
ANTES (Dm):          DESPUÉS (G):
Soprano: F ────────→ G (salta tercera, OK épico)
Alto: A ────────→ B (salta tercera, paralelo soprano)
Tenor: D ────────→ G (salta cuarta, movimiento lógico)
Bass: D ────────→ G (salta quinta, root movement)

Resultado: Sonoridad suave, sin disonancia "pega"
```

### Inversiones Útiles

**Primera Inversión (3ª en bajo):**
- Em/G: G-B-E (suave, no drástico)

**Segunda Inversión (5ª en bajo):**
- Em/B: B-E-G (tensión máxima, cadencial)

## ORQUESTACIÓN ESPECÍFICA

### Guitarra Eléctrica
- **Clean (Verses):** 8-12 kHz presencia
- **Heavy distortion (Chorus):** 4-6 kHz power
- **Lead solo:** 10-15 kHz claridad
- **Rhythm power chords:** 2-4 kHz grasa

### Bajo Eléctrico
- Rango: 40-250 Hz
- **Verso:** Root movement suave
- **Coro:** Root + fifth power
- **Bridge:** Movimiento complementario
- Ejemplo Em: E (root) o E-B (octava)

### Batería
- **Verso:** Kick simple, snare backbeat
- **Coro:** Doble kick, snare agresivo
- **Bridge:** Doble kick máximo, tom fills
- **Vel. BPM Power (160):** Doble kick 320 notas/min

### Sintetizador/Teclado
- **Pad:** Sustain emocional (background)
- **Swell:** Construcción gradual
- **Arpeggio:** Movimiento rítmico
- **Orchestral:** Strings, choir, brass simulation

### Strings (Symphonic Metal)
- **Verso:** Pizzicato o sustain suave
- **Coro:** Full sustain emocional
- **Bridge:** Violín solo + soporte
- **Arreglo:** 3-parte (Violin I, Violin II, Cello)
