## 📋 ORDEN DE INSTALACIÓN EN GEM:

### PASO 1: Abre tu GEM en gemini.google.com

```
Click: "Create a custom GEM"
Nombre: "LYRICA METAL V5.1 PRO"
```

### PASO 2: Carga KNOWLEDGE BASE

```
Ubicación: Settings → Customize this GEM → Knowledge
Click: "+ Add knowledge" o "Upload file"

Opción A (Upload directo):
  ├─ Click "Upload file"
  ├─ Selecciona: LYRICA-V5.1-KNOWLEDGE-BASE.md
  └─ Espera a que cargue

Opción B (Copy-paste):
  ├─ Abre: LYRICA-V5.1-KNOWLEDGE-BASE.md
  ├─ Ctrl+A (Select All)
  ├─ Ctrl+C (Copy)
  ├─ En GEM → Knowledge → "+ New document"
  ├─ Ctrl+V (Paste)
  └─ Guardar
```

### PASO 3: Carga INSTRUCCIONES

```
Ubicación: Settings → Customize this GEM → Instructions

1. Abre: LYRICA-V5.1-INSTRUCCIONES-FINAL.md
2. Ctrl+A (Select All)
3. Ctrl+C (Copy)
4. En GEM → Instructions
5. Borra lo que haya
6. Ctrl+V (Paste)
7. Guardar
```

### PASO 4: Guarda el GEM

```
Click "Save" o "Create GEM"
Nombre confirmado: "LYRICA METAL V5.1 PRO"
```

### PASO 5: Prueba en Chat

```
Pega una letra de metal:

  "En el alma oscura existe una voz
   Que grita por libertad y honor
   En batallas sin fin, bajo reyes de furor
   Buscamos la gloria en cada dolor"

Verifica que GEM responda con:
  ✅ Análisis profundo (10-15 líneas)
  ✅ Subgénero detectado
  ✅ 5 bloques SUNO listos para copiar
```
