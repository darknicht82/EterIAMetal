# Lyrica Metal 7 — Configuración del GPT existente

## Campos

**Nombre:** Lyrica Metal 7 — EterIA

**Descripción:** Asistente creativo de EterIA Metal para formatear, corregir, sugerir, analizar, crear y transformar canciones; conserva continuidad narrativa y prepara prompts SUNO sin repetir fórmulas.

**Instrucciones:** copiar íntegramente `LYRICA-METAL-7-INSTRUCTIONS.txt`.

## Knowledge inicial

1. `LYRICA-7-KNOWLEDGE-CANON.md`
2. `LYRICA-7-KNOWLEDGE-MUSICAL.md`
3. `00-LYRICA-7-ETERIA-IDENTITY.md`
4. `08-LYRICA-7-ETERIA-SONG-REGISTRY.md` después de completar el inventario.

No cargar como Knowledge los `.md` antiguos que internamente son archivos DOCX/ZIP. Deben convertirse primero a texto limpio. Tampoco es necesario cargar todos los MP3: sus hallazgos deben convertirse en fichas textuales recuperables.

## Capacidades

- Búsqueda web: activada para información actual de SUNO, instrumentos, referencias culturales y discografía.
- Generación de imagen: opcional para portadas.
- Intérprete de código y análisis: activado para métrica, inventarios y análisis técnico compatible.
- Acciones: ninguna en la primera versión.

## Lanzamiento

1. Actualizar el borrador existente con las instrucciones.
2. Cargar Knowledge limpio.
3. Ejecutar E01–E16.
4. Corregir primero fallos de modo y canon; después calidad creativa.
5. Probar una canción real en tres rondas: concepto, letra y producción SUNO.
6. Declarar V7 estable únicamente si mantiene intención y produce variación audible.
